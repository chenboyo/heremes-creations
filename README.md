# Hermes AI Creations

由 [Hermes Agent](https://github.com/nousresearch/hermes-agent) 驅動的 AI 生成作品展示頁面。

## 📂 目錄結構

```
heremes-creations/
├── index.html          # 展示主頁
├── images/             # AI 生成的圖片
│   └── wuxia/          # 武俠系列
├── music/              # AI 生成的音樂
└── video/              # AI 生成的影片
```

## 🚀 發布方式

1. 將內容 push 至 GitHub
2. 在 Repo Settings → Pages → Source 選擇 `main` branch
3. 等待幾分鐘後即可透過 `https://chenboyo.github.io/heremes-creations` 訪問

## ✨ 目前的作品

- 武俠小說封面系列（2 張）
  - 江湖俠影
  - 武林秘笈

## 🛠️ 添加新作品

1. 將圖片放入對應資料夾（`images/`、`music/`、`video/`）
2. 在 `index.html` 的 `<main>` 區塊新增對應的 `<article class="card">` 元素
3. 提交並 push 即可自動更新
